### Root cause
The `inlineLocalImages` function in `src/export/exportNoteHtml.ts` used the regex
`/<img\b[^>]*>/gi` to find image tags. The `[^>]*` stops at the FIRST `>`, which can sit
inside a quoted attribute value (e.g. `alt="a > b"`). When such a value precedes `src=`,
the tag match is truncated before `src`, the inner scan finds no `src=`, and the image
is silently left un-inlined in the standalone export.

### Fix
Replaced the tag regex with `/<img\b(?:[^>'"]|"[^"]*"|'[^']*')*>/gi`, which jumps over
quoted attribute values and only terminates on a bare, unquoted `>`. Added a regression
test: `<img alt="a > b" src="asset://image/20">` is now correctly inlined to a data URI.
