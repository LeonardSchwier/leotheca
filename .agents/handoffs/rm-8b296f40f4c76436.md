Fixed by making both the lookahead and the capture group quote-aware: an `ATTRS` sub-pattern (`(?:"[^"]*"|'[^']*'|[^>"'])*`) treats a whole `"..."`/`'...'` value as one atomic unit even when it contains `>`, so an embedded `>` inside a quoted value can never be mistaken for the tag's own close.
