## Acceptance Criteria

Typing `/` at the start of a line in the CodeMirror editor opens a
quick-insert completion menu for common Markdown constructs. The menu
complements the existing Command Palette (app-wide actions) by providing
inline content insertion while typing.

### Commands implemented

| Command | Label | Inserts |
|---------|-------|---------|
| `/table` | table | 3-column Markdown table with header, separator, 2 data rows |
| `/task` | task | `- [ ] ` task-list item |
| `/heading` | heading | `## Heading` |
| `/h1` | h1 | `# Heading` |
| `/h2` | h2 | `## Heading` |
| `/h3` | h3 | `### Heading` |
| `/link` | link | `[label](url)` |
| `/code` | code | fenced code block (``` ``` ``` fences) |
| `/quote` | quote | `> ` blockquote line |
| `/callout` | callout | Obsidian `> [!note]` callout |
| `/hr` | hr | `---` horizontal rule |
| `/list` | list | `- ` bullet list item |
| `/ol` | ol | `1. ` ordered list item |
| `/image` | image | `![alt](url)` |
| `/math` | math | `$$\n$\n$$` math block |
| `/footnote` | footnote | `[^1]: ` footnote definition |

### Trigger rules

- `/` must be at the start of a line (no leading non-space chars)
- Must be followed by at least one command-name character (`[a-zA-Z0-9-]`)
- Bare `/` (no command name) does not trigger
- `/` mid-line does not trigger
- Query filtering is case-insensitive substring match on label + description

## Self-Review Findings

1. **Type safety:** The test `makeContext()` helper builds a minimal
   object and casts it to `CompletionContext` via `as unknown as`.
   This is necessary because `CompletionContext` requires properties
   (`explicit`, `tokenBefore`, `aborted`, `addEventListener`) that are
   irrelevant to our code path. The cast is scoped to the test file
   only; production code uses the full `CompletionContext` from
   `@codemirror/autocomplete`.

2. **Trigger scope:** `slashCommandCompletions` returns `null` for
   non-slash contexts, so it does not interfere with existing
   wikilink, heading-link, or block-link completions. The autocompletion
   framework iterates overrides in order and uses the first non-null
   result.

3. **No new dependencies:** Uses only `@codemirror/autocomplete`
   (already a project dependency) and `@codemirror/state` (already a
   project dependency).

4. **No UI changes:** This is purely a completion override — the
   CodeMirror completion UI (popup, keyboard navigation) is handled
   by the `autocompletion()` extension already in the editor.
