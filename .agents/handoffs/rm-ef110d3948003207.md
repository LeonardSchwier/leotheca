## Bug

`src/capture/captureCommit.ts` had two related bugs in attachment filename generation:

1. **Colon bug (all platforms):** `.replace(":", "-")` only replaces the **first** colon, leaving the second one intact. Generated filenames like `capture-2026-09-21-17-24:00-abc123-photo.jpg` still contain a colon, which is invalid on some filesystems and violates F05 §9.3.

2. **UTC vs local time (non-UTC timezones):** `new Date().toISOString()` always returns UTC, but F05 §9.3 requires `capture-<local-date>-<local-time>-<short-random>-<safe-name>.<ext>`.

Both `generateAttachmentFilename` (line 122) and `createNoteWithTitle`'s timestamp base name (line 331) had the same bugs.

## Fix

Replaced `toISOString()` with explicit local-time component extraction (`getFullYear()`, `getMonth()`, `getDate()`, `getHours()`, `getMinutes()`, `getSeconds()`) in both functions. The colon bug was fixed as a side effect (local time components don't contain colons).
