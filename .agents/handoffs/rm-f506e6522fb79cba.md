## Summary

The CodeMirror linter extension created for the offline spellcheck feature
(`spellCheckExtension` in `src/spellcheck/spellCheck.ts`) cached a `null`
checker permanently on its first lint pass. If that first pass fired before
the editor's `useEffect` had populated the dictionary refs (`.aff`/`.dic`
content), the linter silently produced `[]` for the entire lifetime of the
view — even after the dictionary had loaded. Spellchecking was therefore
permanently dead for any editor that ran its first lint pass during the
load window.

## Acceptance criteria

1. `spellCheckExtension` returns a linter whose source, when the first
   `createChecker()` call returns `null` (dictionary not yet loaded) and a
   later call returns a working checker (dictionary now loaded), produces
   diagnostics on the later pass. (This is the core regression.)
2. The "missing dictionary → silently off" contract is preserved: if
   `createChecker()` keeps returning `null` (files genuinely absent), the
   linter keeps returning `[]` on every pass without throwing or attempting
   a real nspell parse.
3. A successful checker is still cached, so the common case keeps the single
   nspell parse (no per-lint-pass dictionary re-parse).
4. Two regression tests encode (1) and (2). Both fail on the pre-fix code
   (proven by stashing the fix and re-running) and pass on the fixed code.

## Root cause

`getChecker()` used a `checkerChecked` boolean latch:

```ts
let cachedChecker: SpellChecker | null = null;
let checkerChecked = false;
function getChecker(): SpellChecker | null {
  if (!checkerChecked) {
    checkerChecked = true;          // ← latched on first pass
    try { cachedChecker = createChecker(); }
    catch { cachedChecker = null; }
  }
  return cachedChecker;
}
```

Once `checkerChecked` was `true`, the checker was never re-derived. A first
pass that saw empty dictionary refs → `null` cached forever.

## Fix

Re-derive the checker on every pass while the cached value is `null`; cache
the first successful result:

```ts
let cachedChecker: SpellChecker | null = null;
function getChecker(): SpellChecker | null {
  if (cachedChecker) return cachedChecker;
  try {
    const next = createChecker();
    if (next) cachedChecker = next;   // success → cache it
    return next;                      // null → not cached; retried next pass
  } catch {
    return null;                      // transient throw; retried next pass
  }
}
```

This preserves the "missing dictionary → silently off" contract (the files
either appear — ref populated → `createChecker()` returns a checker, or they
don't — `createChecker()` keeps returning `null` quickly via its empty-dic
guard, no nspell parse). It also survives a transient first-pass throw.
