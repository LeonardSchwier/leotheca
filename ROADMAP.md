# Roadmap

The ledger for all work on Leotheca: one entry per piece of work, one owner at a time. Entries are read and written by `scripts/agent_ledger.py`; never hand-edit an `agent-state` comment. How to claim, work and finish an item: [`skills/roadmap-workflow.md`](skills/roadmap-workflow.md). How to write an entry: [`skills/roadmap-entry-format.md`](skills/roadmap-entry-format.md). Rules: [`CONSTITUTION.md`](CONSTITUTION.md). Who works on the project and how: [`documentation/AGENTIC_PDLC.md`](documentation/AGENTIC_PDLC.md).

| Icon | Meaning |
| --- | --- |
| ⬜ | Available: claim it if its dependencies and scope fit. |
| 🚧 | Owned: a lease is running, or it expired and the item is recoverable. |
| ⏸ | Blocked on something outside the repository (credentials, a device, an external review). |
| ✅ | Shipped, with the evidence recorded in its entry. |
