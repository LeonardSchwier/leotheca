# Whisper.cpp FFI Integration for LeoTheca

This directory contains the Rust FFI bindings for integrating [whisper.cpp](https://github.com/ggerganov/whisper.cpp) into LeoTheca for offline speech-to-text recognition.

## Overview

This module provides:
- Rust-safe wrappers around whisper.cpp's C API
- Automatic compilation of whisper.cpp source code via build script
- FFI bindings generated by bindgen
- Integration with Tauri for desktop speech recognition

## Usage

### Prerequisites

To enable actual whisper.cpp speech recognition (not just stubs), you need:

1. **whisper.cpp source code** - Place `whisper.cpp` and `whisper.h` in this directory
2. **GGML model files** - Download model files (e.g., `ggml-tiny.bin`) and place them in your app directory

### Obtaining whisper.cpp

```bash
# Clone whisper.cpp repository
git clone https://github.com/ggerganov/whisper.cpp.git

# Copy the necessary files to this directory
cp whisper.cpp/whisper.cpp src-tauri/native/whisper/
cp whisper.cpp/whisper.h src-tauri/native/whisper/
```

### Downloading Models

Download GGML models from:
- https://huggingface.co/ggerganov/whisper.cpp/tree/main
- https://ggml.org/

Recommended models:
- `ggml-tiny.bin` (39 MB) - Fast, good for quick notes
- `ggml-base.bin` (75 MB) - Balanced accuracy and speed
- `ggml-small.bin` (244 MB) - Better accuracy, slower
- `ggml-medium.bin` (769 MB) - High accuracy, requires more RAM

Place the downloaded `.bin` files in your app's working directory or configure the model path in the application settings.

## Building

Once whisper.cpp source is in place, the build script will automatically:

1. Detect the presence of whisper.cpp and whisper.h
2. Compile whisper.cpp as a static library using the `cc` crate
3. Generate Rust FFI bindings using bindgen
4. Link everything together

```bash
cd src-tauri
cargo build
```

If whisper.cpp source is not present, the build script will:
- Issue a warning (not an error)
- Generate stub bindings that simulate the API
- Allow the application to compile and run with placeholder functionality

## Integration with Tauri

The `speech_commands.rs` module in `src-tauri/src/` provides Tauri commands that use this FFI module:

- `init_speech_recognition` - Load a whisper model
- `transcribe_audio` - Transcribe audio samples
- `get_speech_status` - Get current speech recognition status
- `get_whisper_models` - Get list of available model configurations
- `check_whisper_models` - Check which model files exist on disk

## API Reference

### `WhisperModel`

Main struct for interacting with whisper.cpp:

```rust
pub struct WhisperModel {
    context: *mut whisper_context,
    sample_rate: u32,
    n_threads: u32,
}

impl WhisperModel {
    pub fn load(model_path: &str) -> Result<Self, String>;
    pub fn transcribe(&self, audio_samples: &[f32]) -> Result<String, String>;
    pub fn transcribe_streaming(&self, audio_samples: &[f32]) -> Result<String, String>;
    pub fn get_info(&self) -> WhisperModelInfo;
    pub fn is_loaded(&self) -> bool;
}
```

### Model Sizes

## Platform Support

### Desktop (Tauri)
- Full whisper.cpp integration with FFI
- Requires whisper.cpp source and model files
- Works on Windows, macOS, and Linux

### Android
- Uses Android's built-in SpeechRecognizer API with `EXTRA_PREFER_OFFLINE`
- No whisper.cpp required
- See `android/app/src/main/java/com/leonardschwier/leotheca/SpeechRecognitionPlugin.java`

## Performance Considerations

1. **Model Size vs Accuracy**: Larger models provide better accuracy but require more RAM and are slower
2. **Thread Count**: The default is 4 threads, but you can adjust this based on your CPU
3. **Sample Rate**: whisper.cpp expects 16kHz mono audio (f32 format)
4. **Memory**: The model is loaded entirely into memory - ensure you have enough RAM

## Troubleshooting

### Compilation Errors

If you see errors during compilation:

1. **Missing whisper.cpp**: Place whisper.cpp and whisper.h in this directory
2. **C++17 required**: Ensure your compiler supports C++17
3. **bindgen issues**: Make sure you have LLVM/clang installed

### Runtime Errors

1. **Model not found**: Ensure the model file path is correct
2. **Out of memory**: Try a smaller model (e.g., tiny instead of medium)
3. **Invalid audio format**: Ensure audio is 16kHz mono f32
