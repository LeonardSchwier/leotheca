What Leotheca does today

A short list of shipped features, each checked against the code. Work in progress, blocked items and plans are not listed here; the roadmap tracks them.

📂 Files and workspace

  • Plain-folder workspace - Open any local folder of Markdown files. No import step, no database, no proprietary format.
  • File tree - Create, rename and move notes and folders; deleted items go to a .trash folder unless you choose permanent deletion.
  • Open files from outside the workspace - Open a Markdown file from the OS file manager into a read-only scratch view.
  • Android folder access - Real folder access through the Storage Access Framework.
  • Workspace statistics - Folder, note and image counts and note dates in Settings.

🖍️ Writing

  • Source, Preview and Split - A CodeMirror 6 source editor with a rendered preview, per note.
  • Autosave and tabs - Edits are saved as you type; several notes open in tabs, with a second editor group on desktop.
  • Slash commands - Type / for table, task and heading snippets.
  • Highlights - ==text== with colour emoji, in the editor and the preview.
  • Math, diagrams and footnotes - KaTeX math and Mermaid diagrams render in the preview, locally; footnotes ([^1]) are supported.
  • Offline spellcheck - Dictionary-based spellchecking without any network access.
  • Right-to-left text - Automatic per-note text direction.
  • Themes and CSS snippets - Light and dark themes following the OS, and custom CSS snippets.

🔗 Links and navigation

  • Wikilinks and backlinks - [[links]] resolved by filename, autocomplete while typing and a backlinks panel.
  • Renaming keeps links working - A rename preview lists the references that would change before they are rewritten.
  • Graph view - A pannable, zoomable map of how notes connect.
  • Full-text search - Across the whole workspace, including hidden dotfiles.
  • Command palette - Ctrl+K for navigation and actions.
  • Bookmarks - For files and saved searches.
  • Workspace health check - Broken links, duplicates and orphans reported in Settings.

🏷️ Structure

  • Frontmatter properties - A Properties panel for YAML frontmatter.
  • Smart collections and kanban - Property-based collections as list, table, card and kanban board views; board columns group values case-insensitively.
  • Task Hub - Every GFM task-list item across the workspace in one place.
  • Tags - Inline #tags and a tags panel.

🎨 Canvas, drawing and PDF

  • Canvas - Place note cards on a whiteboard and connect them.
  • Freehand drawing notes - Ink notes stored as plain .ink files.
  • PDF viewing and annotation - Read PDFs and annotate them with ink, sticky notes and shapes.
  • Attachments - Images display in the preview with a fullscreen zoom viewer.

📤 Capture and export

  • Quick capture - Capture text or images into an inbox note.
  • Export and print (desktop) - Export a note to standalone HTML, or print it through the OS dialog.
  • Optional web clipper - A separate browser extension that saves a page selection as a Markdown file through the browser's save dialog. It never talks to the app. Install notes.
